# 摘要

随着城市化进程加快和机动车保有量增长，交通拥堵成为制约城市发展的突出问题。拼车模式作为共享经济典型应用，可有效减少车辆数量、提高道路利用率。本课题设计实现了集实时交通监测与拼车服务于一体的综合系统，旨在提供路况查询和拼车匹配平台，缓解交通压力。

系统采用前后端分离架构：前端基于Vue 3框架，结合Vue Router、Pinia、Element Plus和ECharts实现界面与可视化；后端采用Spring Boot框架，使用JWT认证和BCrypt加密；数据库选用MySQL，设计7个核心数据表，遵循第三范式，并通过索引优化和适度反规范化平衡查询性能。

系统包含四大功能模块：用户管理模块支持注册、登录及信息管理；实时交通监测模块通过Python脚本采集数据，提供多维度查询与分析；拼车服务模块支持需求发布、智能搜索与行程跟踪；数据采集模块定期自动采集数据，具备容错机制。

技术实现上采用RESTful API规范，安全性通过JWT和BCrypt保障，性能方面建立复合索引并实现前端优化。测试表明系统可支持100并发用户，平均响应时间小于300ms。

数据库设计是核心，通过概念设计识别7个实体及其关系，绘制E-R图并转换为关系模型，定义表结构与索引。设计存储过程封装复杂业务逻辑，保证事务原子性。

项目历时8周完成，深入理解了全栈开发流程，掌握了Vue 3、Spring Boot、MySQL等技术。系统具备基本功能，但在实时位置追踪、信用体系等方面仍有改进空间。未来可扩展至更多城市，引入智能推荐算法，进一步提升用户体验。

**关键词**：交通监测；拼车系统；Vue 3；Spring Boot；MySQL；数据库设计；RESTful API
